# ♛ ChessHub

پلتفرم حرفه‌ای شطرنج آنلاین — پازل روزانه، اسکین مهره‌ها، تم‌های رنگی و بک‌اند بدون وابستگی.

> **بدون هیچ وابستگی خارجی** — فقط Node.js کافیست. حتی `npm install` هم لازم نیست.

> 📘 **راهنمای کامل مدیر سایت** (پر کردن داده‌ها، مهره‌ها، انتشار در GitHub و Render):
> فایل **`README-FA.md`** را بخوان — همه‌چیز قدم‌به‌قدم آنجاست.

---

## 🚀 اجرای محلی

```bash
node server.js
```

سپس در مرورگر: **http://localhost:3000**

تغییر پورت (اختیاری):

```bash
PORT=8080 node server.js
```

## ☁️ دیپلوی روی Render.com

### روش ۱ — Blueprint (سریع‌ترین راه)
1. پروژه را در GitHub منتشر کن
2. در [Render](https://dashboard.render.com) → **New** → **Blueprint**
3. ریپو را انتخاب کن — فایل `render.yaml` همه‌چیز را خودکار تنظیم می‌کند ✅

### روش ۲ — Web Service دستی
| تنظیم | مقدار |
|---|---|
| Runtime | **Node** |
| Build Command | `npm install` (یا خالی) |
| Start Command | `npm start` |
| Health Check Path | `/api/health` |

پورت را Render خودش با متغیر `PORT` تنظیم می‌کند — نیازی به کاری نیست.

## 👥 بازی آنلاین

- آدرس: **online.html** — پروفایل (نام هر ۱۵ روز + آواتار آزاد)، ریتینگ Elo (K=32)،
  بازی سریع، دعوت بازیکنان، تماشای بازی‌های زنده، چت بازیکن‌ها، تاریخچه با مرور بازی
- زمان‌ها: ۱+۰ تا ۳۰+۰ + **زمان سفارشی** دلخواه
- قواعد ضدتقلب: لغو خودکار اگر تا ۱۵ ثانیه حرکتی زده نشود، قطعی اینترنت
  = ۱۵ ثانیه مهلت (وگرنه باخت)، ساعت سمت سرور، اعتبارسنجی همه‌ی حرکات
- داده‌ها: `data/users.json` (پروفایل‌ها) و `data/online_games.json`
  (**همه‌ی** بازی‌های سایت — فایل مدیر؛ کاربران فقط بازی‌های خودشان را می‌بینند)
- WebSocket خالص RFC 6455 با crypto خود Node — روی Render مستقیم کار می‌کند

## 🤖 بازی با بات + مرور بازی

- آدرس: **engine-game.html** — ۳۵ بات از ریتینگ ۲۵۰ تا ۲۸۸۲؛ هر بات دقیقاً
  هم‌اندازه‌ی ریتینگش بازی می‌کند و سبک دارد (تهاجمی/منظم/موقعیتی/تله‌گذار/غیرقابل پیش‌بینی)
- ساعت استاندارد + سفارشی؛ PGN؛ و پس از پایان هر بازی دکمه‌ی **مرور بازی**:
  نمره‌ی هر حرکت (برترین/عالی/خوب/بی‌دقتی/اشتباه/فاجعه)، نمودار برتری، فلش سبز
  بهترین حرکت و دقت درصدی — همین مرور در بازی آنلاین و پایگاه بازی‌ها هم هست
- عکس بات‌ها: `images/bots/1.png` تا `35.png` (تا آن‌موقع فالبک خودکار)

## 🧩 پازل روزانه

- منبع داده: **`data/daily_puzzle.txt`** (اگر نبود: `daily_puzzle.csv`)
- فرمت: استاندارد **Lichess** — با یا بدون سطر هدر (خودکار تشخیص داده می‌شود):

```
PuzzleId,FEN,Moves,Rating,RatingDeviation,Popularity,NbPlays,Themes,GameUrl,OpeningTags
```

- **چرخش:** روز اول = سطر اول؛ هر ۲۴ ساعت (بر پایه UTC) یک سطر جلوتر؛ بعد از آخرین سطر از اول تکرار می‌شود
- حرکت اول هر پازل به‌صورت خودکار توسط حریف بازی می‌شود و کاربر با رنگ مقابل باید دنباله را کامل کند

## 🎨 شخصی‌سازی (فقط کپی کن!)

| پوشه | محتوا |
|---|---|
| `pieces/<نام‌مجموعه>/` | ۱۲ فایل PNG مهره: `wp wn wb wr wq wk bp bn bb br bq bk` |
| `data/daily_puzzle.txt` | دیتابیس پازل‌های خودت |

۳۸ مجموعه مهره و ۲۹ تم رنگی از صفحه **تنظیمات** قابل انتخاب هستند؛ مجموعه‌ای که تصویر نداشته باشد به‌صورت خودکار با نماد یونیکد نمایش داده می‌شود.

## 🔒 امنیت بک‌اند

- محافظت از Path Traversal (حتی مسیرهای انکودشده)
- مسدود شدن فایل‌های حساس (`server.js`, `package.json`, ...)
- هدرهای امنیتی: `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`
- فشرده‌سازی Gzip خودکار + ETag/304
- خاموشی تمیز با SIGTERM (سازگار با دیپلوی Render)
