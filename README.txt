♛ ChessHub — نسخه حرفه‌ای (ماموریت ۱)
========================================

محتویات:
  index.html            صفحه اصلی (شامل «مسئله روز»)
  header.html           هدر مشترک همه صفحات
  footer.html           فوتر مشترک همه صفحات
  css/style.css         استایل کامل سایت (وزیر + لاله‌زار، سفید/مشکی، ریسپانسیو)
  js/script.js          اسکریپت اصلی: تزریق هدر/فوتر، منو، تنظیمات،
                        ChessUtils (مهره/صدا/ترفیع) و موتور مسئله روز
  data/daily_puzzle.csv نمونه پازل‌ها ← فایل اصلی خودت را جایگزین کن
  pieces/               پوشه مهره‌ها ← خودت تصاویر را بچین (راهنما داخلش)
  boards/               پوشه تخته‌ها ← خودت تصاویر را بچین (راهنما داخلش)

──────────────────────────────────────────────
▶ روش اجرا (مهم)
──────────────────────────────────────────────
بهترین حالت: اجرا با Local Server (چون مرورگرها fetch از file:// را می‌بندند):

  روش ۱: VS Code → افزونه Live Server → راست‌کلیک روی index.html → Open with Live Server
  روش ۲: در همین پوشه دستور زیر را بزن و بعد http://localhost:8000 را باز کن:
         python -m http.server 8000

باز کردن مستقیم index.html (دابل‌کلیک) هم کار می‌کند؛ در این حالت اسکریپت
به‌صورت خودکار هدر/فوتر ساده و پازل نمونه داخلی را نمایش می‌دهد تا سایت
همیشه زنده باشد.

──────────────────────────────────────────────
♟ مهره‌ها
──────────────────────────────────────────────
هر ست مهره یک پوشه داخل pieces/ با ۱۲ فایل:
  wp wn wb wr wq wk bp bn bb br bq bk  (همگی .png)
مثال: pieces/neo/wp.png
ست پیش‌فرض: neo (قابل تغییر از تنظیمات)
تا جای‌گذاری تصاویر، فالبک خودکار یونیکد فعال است.

──────────────────────────────────────────────
🖼 صفحه‌ها (تخته‌ها)
──────────────────────────────────────────────
فایل‌های PNG تخته را در boards/ بگذار (نسبت ۱:۱).
فعال‌سازی: chesshub_settings → {"board": "نام-فایل"} بدون پسوند .png
اگر فایل نباشد، خودکار به تخته رنگی تم برمی‌گردد.

──────────────────────────────────────────────
🧩 مسئله روز
──────────────────────────────────────────────
فایل: data/daily_puzzle.csv
ساختار ستون‌ها (سازگار با دیتابیس رسمی Lichess):
  PuzzleId,FEN,Moves,Rating,RatingDeviation,Popularity,NbPlays,Themes,GameUrl,OpeningTags

  - Moves: حرکت‌های UCI با فاصله؛ «حرکت اول» مالِ حریف است (شروع‌کننده)
    و پازل بعد از آن برای کاربر شروع می‌شود.
    مثال: h7h6 d5c7 e8e7 c7a8
  - Themes: کلیدهای لیشس با فاصله (mateIn1, fork, pin, ...)
    کلیدهای معروف فارسی‌سازی شده‌اند.
  - هر روز به‌طور خودکار یک ردیف از فایل انتخاب می‌شود (چرخش روزانه قطعی).
  - دیتابیس کامل: lichess.org → مسیر database → فایل puzzles.csv

فایل CSV نمونه کنونی ۵ پازل تست‌شده دارد؛ فایل اصلی خودت را با همین
نام و ساختار جایگزین کن.

──────────────────────────────────────────────
⚙️ تنظیمات
──────────────────────────────────────────────
در localStorage با کلید chesshub_settings ذخیره می‌شود:
  {"pieceSet":"neo", "theme":"1", "board":null, "sound":true}

  - pieceSet : نام پوشه ست مهره در pieces/
  - theme    : شماره تم رنگی تخته (theme-1 تا theme-29)
  - board    : نام فایل تخته PNG در boards/ (یا null)
  - sound    : روشن/خاموش بودن افکت‌های صوتی

صفحات دیگر از همین اسکریپت مشترک استفاده می‌کنند؛ کافیست در هر صفحه جدید:
  <div id="header-placeholder"></div>
  ... محتوای صفحه ...
  <div id="footer-placeholder"></div>
  <script src="js/script.js"></script>
هدر و فوتر خودکار تزریق می‌شوند.
