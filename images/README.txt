📷 عکس‌ها — فقط کافیست فایل‌ها را با همین نام‌ها بگذاری:
  images/bots/1.png … 35.png        → عکس ۳۵ بات (به ترتیب فهرست js/bots.js)
  images/players/carlsen.jpg …      → عکس استادان (پایگاه بازی‌ها + دانلود PGN)
  images/avatars/1.png … 8.png      → آواتارهای آماده‌ی بازی آنلاین
تا وقتی عکس نگذاری، سایت خودش فالبک زیبا نشان می‌دهد.
