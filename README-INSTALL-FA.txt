چی داخل پک است؟
  apply-v1134.py          ← نصب‌کنندهٔ خودکار (همه‌چیز را پچ می‌کند)
  gamereview.js           ← موتور مرور بازی جدید (دو مرحله‌ای، دقیق‌تر)
  game-review.html        ← صفحهٔ مرور بازی جدید
  gamereview-delta.css    ← دلتای استایل مرور (نصب‌کننده به css/gamereview.css می‌چسباند)
  admin-v1134.css         ← استایل اختصاصی جدید پنل ادمین
  README-INSTALL-FA.txt   ← همین فایل

نصب — فقط ۳ قدم:
  ۱) محتوای این پک را کنار پوشهٔ chesshub خودت بریز
     (یا فایل‌ها را داخل پوشهٔ chesshub کپی کن)
  ۲) داخل پوشهٔ chesshub این دستور را اجرا کن:
        python apply-v1134.py
     (اگر پوشهٔ chesshub جای دیگری است: python apply-v1134.py مسیر/پوشه/chesshub)
  ۳) server.js را ری‌استارت کن و صفحات را با Ctrl+F5 باز کن

تغییرات این نسخه (به‌علاوهٔ همهٔ v11.33):
  • مرور بازی خیلی دقیق‌تر: موتور دومرحله‌ای + درخشانِ واقعی (قربانیِ
    جبران‌نشده) + آستانه‌های دقیق — نه برچسب الکی، نه درخشان الکی
  • علامت‌ها روی گوشهٔ راست خانهٔ مقصد + آیکن قبل از متن حرکت
  • شمارندهٔ حرکت کامل (۲۹ حرکتی → «/۲۹»)
  • نوار ارزیابی دقیق با منحنی شانس برد لایچس (−۵ پیاده = سرخ سنگین)
  • فونت تمیز حرکات و اعداد ارزیابی (لاتین استاندارد)
  • گزارش عملکرد: پنل پهن‌تر + داوری متنی روان + چیپ‌های منظم دوستونه
  • آواتار بزرگ‌تر (نوار ۴۴px، گزارش ۹۶px) + آدمک «پیادهٔ شطرنج»
    سفید برای سفیدِ بی‌عکس و سیاه برای سیاهِ بی‌عکس
  • «تحلیل بازی» و «تحلیل در آنالیز»: حالا PGN واقعاً در آنالیز لود
    می‌شود (لودر با تأییدِ موفقیت و تلاش مجدد تا آماده‌شدن صفحه)
  • نمایش بازی: نوشتهٔ راهنما حذف شد + عکس بازیکنان بزرگ‌تر (۴۶px)
  • پازل روزانه: کارت پازل دقیقاً زیر نوشتهٔ «پازل روزانه / هر روز یک
    پازل تازه» می‌نشیند
  • پنل ادمین: استایل اختصاصی جدید (فونت، دکمه‌ها، جدول‌ها، فرم‌ها)

نکتهٔ مهم دربارهٔ «ویرایش کامل + سطل بازیافت + حذف دائمی» پنل ادمین:
  این بخش به فایل‌های دقیق نسخهٔ مستقر تو (admin.html / js/panel.js /
  server.js) نیاز دارد تا بدون رگرسیون وصل شود. اگر پوشهٔ chesshub
  فعلی خودت (همان که سایت از آن اجرا می‌شود) را زیپ کنی و برایم بگذاری،
  قدم بعد را در چند دقیقه کامل می‌کنم — ویرایش همهٔ فیلدهای مقالات/
  دروس/گشایش‌ها + حذفِ نرم + بازگردانی + حذفِ دائمی.
