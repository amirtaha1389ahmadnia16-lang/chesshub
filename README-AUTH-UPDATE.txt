# ChessHub — به‌روزرسانی v9.1 «صفحه ورود/ثبت‌نام + رفع خطاها»

## ⚠️ نکته مهم درباره ریپو
مخزن گیت‌هاب فعلاً هیچ‌کدام از فایل‌های صفحه ورود را ندارد
(login.html و js/login.js وجود ندارند و نسخه‌های js/auth.js و
server.js و server-auth.js روی ریپو قدیمی هستند).
پس فقط فایل‌های این مرحله را آپلود نکن — هر ۶ فایل زیر را کنار هم
با همان مسیر آپلود کن، وگرنه سایت به‌هم می‌ریزد.

## فایل‌های این زیپ (هر ۶ فایل باید آپلود شوند)

| فایل | وضعیت | تغییر این مرحله |
|---|---|---|
| `login.html` | جدید + ویرایش این مرحله | حذف آیکن وزیر از پس‌زمینه شطرنجی (آیکن شاه و بقیه طرح دست‌نخورده) |
| `js/login.js` | جدید + ویرایش این مرحله | رفع خطای `login.js:277` — کلید جاافتاده `upgradeForm` به نگاشت `el` اضافه شد + گارد وجود المان |
| `js/auth.js` | بازنویسی + ویرایش این مرحله | خروج از حساب → انتقال مستقیم به login.html بدون هیچ پیام اضافه؛ هر بازدید بدون نشست از هر صفحه → انتقال مستقیم به login.html |
| `server.js` | تغییر مرحله قبل (هنوز روی ریپو نیست) | ارسال ایمیل در ثبت‌نام |
| `server-auth.js` | تغییر مرحله قبل (هنوز روی ریپو نیست) | ایمیل الزامی/یکتا + ورود با ایمیل یا نام + آواتار پیش‌فرض خودکار |
| `README-AUTH-UPDATE.txt` | راهنما | همین فایل |

## نصب
۱) هر ۶ فایل را دقیقاً با همان مسیر روی ریپو جایگزین/اضافه کن.
۲) commit و push کن.
۳) در Render دکمه Manual Deploy → Deploy latest commit را بزن.

## رفتارهای جدید این مرحله
- خروج از حساب (دکمه «خروج از حساب» در پنجره پروفایل): بدون هیچ
  پیام یا صفحه واسط، مستقیم به login.html می‌رود.
- هر کسی بدون نشست باز کند هر صفحه‌ای از سایت، مستقیم به
  login.html هدایت می‌شود (استثنای «وسط بازی» حذف شد).
- آیکن وزیر از پس‌زمینه صفحه ورود حذف شد؛ بقیه اجزای پس‌زمینه
  (خانه‌های شطرنجی و آیکن شاه) همان است.
- خطای کنسول `login.js:277` (Cannot read properties of undefined)
  رفع شد — علت: کلید `upgradeForm` در نگاشت المان‌ها ثبت نشده بود.
